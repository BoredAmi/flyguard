Corridor Run

Steering is not in the connectome. LPLC2/LC4 reach the Giant Fiber (DNp01) and have zero direct edges onto the fly's steering neurons, so the measured circuit can command stop, never turn. The turn command here compares the two hemispheres' LPLC2 population rates and turns away from the louder one -- real ingredients, but the comparison operator is an engineering addition, not something read off the wiring diagram.
